## 🚀 Atualmente trabalhando em

### Plataforma de Aprendizagem Corporativa

Uma aplicação full stack inspirada em experiências como Duolingo, voltada para capacitação operacional em contextos reais de atendimento ao cliente.

O projeto foi desenvolvido com foco em:

- lições interativas;
- módulos e aulas;
- revisão de erros;
- XP, estrelas e progresso;
- autenticação JWT;
- perfil de usuário;
- matrícula/código de convite;
- backend Java como fonte oficial das regras de aprendizagem;
- conteúdo dinâmico persistido em MySQL;
- deploy automatizado em ambiente cloud.

A ideia central é criar uma solução escalável para capacitação de colaboradores, especialmente em cenários onde comunicação, agilidade, padronização e experiência do cliente fazem diferença.

## 💡 Como penso desenvolvimento

Acredito que código bom não é apenas código que funciona.

Para mim, uma boa solução precisa ser:

- simples de manter;
- clara para evoluir;
- segura nas regras principais;
- útil para pessoas reais;
- construída com visão de produto;
- preparada para crescer sem acumular dívida técnica desnecessária.

Tenho interesse especial por sistemas que resolvem problemas operacionais reais e que podem gerar impacto prático no dia a dia das pessoas.
